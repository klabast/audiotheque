# Screenshots

Drop PNG files here and reference them from the project README:

```markdown
![Library view](docs/screenshots/library.png)
```

Suggested set (none required, all helpful):

- `library.png` — main library / album grid
- `album.png` — album detail with track list
- `player.png` — full-screen player
- `mobile.png` — mobile player
- `devices.png` — device picker / transfer playback
- `settings.png` — settings page

Keep images under ~500 KB each. PNG is fine for the UI chrome; JPEG/WebP for
album-art-heavy shots.
