# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

## TL;DR

- Be respectful.
- Be patient.
- Assume good intent; explain when you can't.
- No personal attacks, harassment, or trolling — in issues, PRs, commit
  messages, or any project space.
- Disagreement on technical decisions is welcome and expected; disagreement
  with how someone exists is not.

## Enforcement

Conduct concerns can be reported by opening a private
[security advisory](https://github.com/klabast/audiotheque/security/advisories/new)
on the repository — that channel is private to maintainers and works for
non-security reports too. For non-confidential matters a regular GitHub
issue is fine. Reports will be reviewed and responded to. Project
maintainers may remove contributions, lock threads, or block contributors
who don't follow the covenant.

## Scope

This applies to all project spaces: the GitHub repository, issue tracker,
pull requests, code review, and any other forum used to coordinate work on
Audiotheque. It also applies when a contributor is officially representing
the project elsewhere.
